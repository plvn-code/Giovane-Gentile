---
description: Сохранить прогресс сессии — обновить документацию и сделать коммит
---

Заверши сессию так, чтобы следующая продолжила без потерь.

1. Обнови документацию по итогам сессии (пиши кратко, по-русски, без воды):
   - `docs/05-changelog.md` — новая запись сверху с сегодняшней датой: что сделано.
   - `docs/04-roadmap.md` — отметь выполненное, добавь новые пункты.
   - `docs/00-handoff.md` — текущее состояние, следующая задача, открытые вопросы, дата обновления.
   - `docs/01-brief.md` — новые требования или правки, которые владелец дал в этой сессии.
   - `docs/03-architecture.md` и `CLAUDE.md` — только если менялась структура: новые файлы, страницы, ключи localStorage, правила.
   - `docs/reference/` — сохрани новые скриншоты референса, если они есть и ещё не сохранены.
2. Проверь `git status` и закоммить всё одним понятным коммитом. Сообщение на английском, в конце строка `Co-Authored-By`.
3. Напомни владельцу нажать **Push origin** в GitHub Desktop. Покажи коротко, что сохранено.
