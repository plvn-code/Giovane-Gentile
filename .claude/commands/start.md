Мы продолжаем делать сайт Giovane Gentile. Быстро войди в контекст и будь готов к следующей задаче.

1. Прочитай `docs/00-handoff.md` (на чём остановились) и `docs/04-roadmap.md`. `CLAUDE.md` уже загружен — следуй его правилам.
2. Проверь репозиторий: `git status -sb` и `git log --oneline -5`. Если есть незакоммиченные изменения или локальная ветка отстаёт от `origin/main`, скажи об этом.
3. Если сервер на порту 5500 не отвечает (`curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:5500/`), запусти его во вкладке терминала: `python3 -m http.server 5500 --bind 127.0.0.1` (заголовок вкладки «site server»). Затем открой превью `giovane-site` во встроенном браузере.
4. Остальные файлы из `docs/` читай по мере надобности, когда задача их касается. Не читай всё подряд.
5. Ответь владельцу по-русски, коротко, 5–8 строк:
   - на чём остановились;
   - 2–3 варианта следующей задачи из roadmap (первым — рекомендуемый);
   - открытые вопросы, если есть.
