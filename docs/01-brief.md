# ТЗ владельца (исходные требования)

Собрано из сообщений владельца проекта. Это первоисточник требований: при сомнениях сверяйся с ним.

## Общее
- Магазин итальянской мужской одежды **Giovane Gentile**. Сайт по образцу https://mozart.boutique/.
- Белый стиль. Фото одежды на моделях пока нет: во всех фото-блоках ставим заглушки («?» или «soon»), потом заменим на фото.

## Главная (MAIN) — `index.html`
- **Шапка:** слева название Giovane Gentile чёрным, красивым шрифтом.
- **Hero:** видеофон — небольшая яхта плывёт по морю днём, солнечно. По центру надпись **Giovane Gentile**, под ней **Prestigious Italian clothing**.
- **Популярні бренди:** 4 плашки с логотипами — Loro Piana, Brunello Cucinelli, ZILLI, Billionaire. Под ними кнопка «Усі бренди».
- **НОВІ НАДХОДЖЕННЯ:** «рулетка» (карусель) квадратных карточек, в центре аккуратно «soon». Формат как на референсе.
- **4 плашки:**
  1. «Преміальний чоловічий трикотаж» + кнопка «До колекції»
  2. «Щоденний образ» + кнопка «Переглянути»
  3. «Зима вже скоро»
  4. «Рюкзаки та аксесуари»
- **SALE:** такая же карусель, в плашках «soon».
- **Контактна форма:** прямоугольная, поля — Ім'я, Номер телефону, Нотатка (вопрос клиента).

### Правки шапки (после первой версии)
- Текст в чёрной полосе: «Italian Quality. Timeless Style.»
- Поиск — квадратный (без скруглений).
- «Кошик» — значок корзины (тележки).
- «Увійти» заменить на «Кабінет».

## Каталог — `catalog.html`
- Разделы: Одяг, Взуття, Аксесуари, Новинки, Sale. У каждого подпункта своя страница.
- На странице 4 карточки в ряд и 5 рядов = **20 карточек**, в центре каждой «SOON».

## Обране (сердечко) — `wishlist.html`
- Товары, отмеченные сердечком. Формат как на референсе (таблица: название, цена, наличие), но качественнее и в нашем стиле.

## Кабінет — `account.html`
- По клику на «Кабінет» открывается окно входа и регистрации.
- **Вход — только по номеру телефона**, клиенту приходит SMS-код.
- **Регистрация:** номер телефона, пароль, подтверждение пароля → «Зареєструватися» → на телефон приходит код → поле для ввода кода из SMS.
- **Разделы кабинета:**
  1. **Особисті дані:** ПІБ, номер телефона, місто, відділення Нової Пошти в его городе.
  2. **Замовлення:** маленькая карточка товара, артикул, размер, статус «оплачено / не оплачено» (кроме полной оплаты можно получить товар на почте, осмотреть и забрать или отказаться), сумма.
  3. **Список бажань:** то, что клиент отметил сердечком.
  4. **Кнопка выхода** из аккаунта.
