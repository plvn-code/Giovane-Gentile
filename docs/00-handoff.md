## Заметки
- Встроенный превью-сервер Claude не может читать папку на Desktop (macOS). Сервер запускать через вкладку терминала: `python3 -m http.server 5500`. `.claude/launch.json` подключает превью к `http://localhost:5500`.
- Push делает владелец через GitHub Desktop: в терминале нет GitHub-авторизации.
- Шапка повторяется в 5 HTML-файлах. Правки шапки вносить во все.
