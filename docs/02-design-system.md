# Дизайн-система

Все токены — в `:root` файла `css/styles.css`.

## Цвета
| Токен | Значение | Где |
|---|---|---|
| `--c-black` | `#111111` | основной текст, кнопки, верхняя полоса |
| `--c-text` | `#1c1c1c` | обычный текст |
| `--c-muted` | `#8a8a85` | второстепенный текст, подписи категорий |
| `--c-line` | `#e6e5e1` | тонкие разделители, рамки |
| `--c-soft` / `--c-soft-2` | `#f5f4f1` / `#ecebe7` | фон заглушек (градиент) |
| `--c-sale` | `#d23a2f` | только SALE, ошибки |
| зелёный | `#2f7a4b` | «Оплачено», «У наявності», «Підтверджено» |
| янтарный | `#a07a2c` / `#a2621f` | «Очікується», «Не оплачено» |
| демо-плашка | фон `#fbf6ea`, полоса `#c9a24a` | пометки «Демо» |

## Шрифты (Google Fonts)
- **Cormorant Garamond** (`--f-logo`) — логотип, крупные заголовки страниц, названия товаров, заголовки hero.
- **Bodoni Moda** (`--f-display`) — вордмарки брендов (Brunello, ZILLI, Billionaire).
- **Montserrat** (`--f-ui`) — меню, заголовки секций (UPPERCASE, letter-spacing .08–.14em), кнопки, формы.

## Элементы
- **Логотип:** «Giovane Gentile» шрифтом Cormorant 600, под ним «— ITALIAN BOUTIQUE —» с линиями.
- **Заголовок секции:** UPPERCASE Montserrat 700, линии по бокам (`.section-title`); без линий — `.section-title--plain`.
- **Кнопки:** прямоугольные, рамка 2px, UPPERCASE.
  - `.btn--outline` — чёрная рамка, при наведении заливка;
  - `.btn--dark` — чёрная;
  - `.btn--light` — для тёмного фона;
  - модификаторы `.btn--small`, `.btn--block`.
- **Поля форм:** `.field` > `.field__label` (UPPERCASE 12px) + `.field__input` (рамка 1px, без скруглений) + `.field__error`. Ошибка — класс `.is-invalid` на `.field`.
- **Карточка товара:** `.card`.
  - `.card__media` — заглушка 3:4, в каталоге 4:5;
  - `.card__soon` — «soon» курсивом, в каталоге `.card__soon--caps` «SOON»;
  - `.card__fav` — сердечко, `.card__badge` — красная метка Sale;
  - `.card__body` — категория и полоски-«скелетоны».
- **Промо-плашка:** `.promo` с «?». Когда появится фото — `style="background-image:url(...)"` и класс `has-image`: текст станет белым, добавится затемнение.
- **Toast:** чёрная плашка внизу экрана, функция `showToast(text, withLink)` в `main.js`.
- **Анимации:** мягкий fade-up при скролле (`.reveal`), учитывается `prefers-reduced-motion`.

## Адаптив
- `≤1280px`: компактнее меню и поиск.
- `≤1100px`: бургер-меню; каталог по 3 в ряд; промо-плашки в 2 колонки; кабинет — вкладки сверху; окно входа в одну колонку.
- `≤760px` (телефон): верхняя полоса только с текстом; «Кабінет» и «Обране» в мобильном меню; каталог по 2 в ряд; карусели со свайпом; окно входа выезжает снизу.
