Відео для першого блоку (hero)

Зараз підключено безкоштовне стокове відео з Pexels (за посиланням).
Щоб поставити своє відео:
1. Покладіть файл сюди з назвою hero.mp4 (бажано 1920x1080, до 10–15 МБ, без звуку).
2. В index.html знайдіть <video class="hero__video" ...> і замініть src на:  assets/video/hero.mp4
